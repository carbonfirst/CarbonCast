# CarbonCast Documentation

Welcome! This folder is the handoff documentation for the CarbonCast workspace.
If you're brand new, start with the top-level [`../HANDOFF.md`](../HANDOFF.md) — it
explains how the three projects fit together. Then dive into whichever guide below
matches what you're working on.

| Doc | Read this when… |
|-----|-----------------|
| [`../HANDOFF.md`](../HANDOFF.md) | You're new and want the big picture + how the pieces connect. |
| [`01-frontend-guide.md`](01-frontend-guide.md) | You're working on the React web app (`CarbonCastUI`). |
| [`02-api-guide.md`](02-api-guide.md) | You're working on the Django API / forecasting backend (`UCSC_CarbonCast_API`). |
| [`03-automation-tool-guide.md`](03-automation-tool-guide.md) | You're working on the RDA weather-download tool (`UCSC_OSRE_CC_automation_tool`). |
| [`04-reorganization-recommendations.md`](04-reorganization-recommendations.md) | You want to clean up / refactor the code safely. |
| [`05-data-and-large-files.md`](05-data-and-large-files.md) | You cloned the repo and the data/models are missing — read why, and how to get them back. |

> These docs describe the codebase as it was at handoff time. Code is the source of
> truth — if a doc and the code disagree, trust the code, then please update the doc
> so the next person isn't misled.
