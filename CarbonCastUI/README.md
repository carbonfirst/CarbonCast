# CarbonCastUI

The CarbonCastUI project is aimed at providing a way to visualize information of the carbon intensity of electricity in selected regions of the world. The map is being styled based on the carbon intensity values obtained from the CSV files that are generated by CarbonCast. Each region on the map is assigned a color based on their carbon intensity value, with darker colors indicating higher carbon intensity and lighter colors indicating lower carbon intensity.

The map's interactivity is implemented using Leaflet.js, where the user can click on a state to zoom in, see more detailed information about the state, and hover over a state to see a tooltip with additional data.

# Requirements
- Python (>= 3.9)
- [CarbonCast](https://github.com/carbonfirst/CarbonCast)

# Setup

First, clone the [CarbonCast](https://github.com/carbonfirst/CarbonCast) respository and swithch to the `CarbonCast` API branch: 

`git clone https://github.com/carbonfirst/CarbonCast.git`

`pushd CarbonCast && git checkout django_apis && popd`

Then, clone our repository:

`git clone https://github.com/carbonfirst/CarbonCastUI`

Your file structure would then have two folders: (i) one with `CarbonCast`, and (ii) another with `CarbonCastUI` (or `CarbonCastUI-main` if you have downloaded this project as a `zip` file). Now, you need to install `CastonCast` dependencies:

`pip3 install -r CarbonCast/requirements.txt`

Then, enter the following command to instantiate `CarbonCast`'s API server:

`python3 CarbonCast/src/CarbonCastAPI/manage.py makemigrations`

`python3 CarbonCast/src/CarbonCastAPI/manage.py migrate`

Then, change directory to `CarbonbCast` and start up the CarbonCast API server:

`pushd CarbonCast && python3 CarbonCast/src/CarbonCastAPI/manage.py runserver --rmauth 0.0.0.0:8000 && popd`

Finally, switch to the `CarbonCastUI` folder (remember to use `CarbonCastUI-main` if this project was downloaded as a `zip` file), and instatiate a local (Python) web server on port `8001`:

`cd CarbonCastUI/CarbonCastUI`

`python3 -m http.server --bind 0.0.0.0 -d . 8001`

Then, open your brownser and browse to the `CarbonCastUI` local address http://127.0.0.1:8001
